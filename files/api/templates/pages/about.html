About FloodWatch

A final-year computer science project shaped as a portable, accessible flood decision-support prototype.

What the system does

FloodWatch receives simulated or hardware-ready sensor readings, persists them in a database, computes risk with transparent rules and ML probability, and presents the outcome through an interactive GIS dashboard plus a screen-reader-accessible station list.

The system does not issue autonomous emergency commands. It supports responders and residents with evidence and safe guidance while directing people to follow official instructions.

Novelty pillars in the actual code

AI plus GIS

ML prediction and threshold logic feed an interactive map and station list.

Portability

Danger levels and source type travel with the station data instead of being hardcoded globally.

Accessibility

Text status, ARIA labels, and readable contrast are included. Flood alerts record web status and email/SMS provider attempts when configured.

Scope control

Account and community-reporting ideas are parked unless the supervisor approves them as extra work.
